# 002

공공이: 주변 공공시설을 카카오 지도와 가까운 순 목록으로 표시합니다.

실행: `npm install` 후 `npm run dev`.
`.env.local`에 `VITE_KAKAO_MAP_KEY`, `VITE_DATA_GO_KR_SERVICE_KEY`를 설정합니다.

금연구역은 [전국금연구역표준데이터](https://www.data.go.kr/data/15013192/standard.do)의
`tn_pubr_public_prhsmk_zn_api`를 사용합니다. 공공데이터포털에서 해당 API 이용이 승인된 인증키가 필요합니다.
카카오 지도 중심의 시·군·구를 확인한 뒤 해당 지역의 모든 페이지를 조회합니다.
주소 검색 또는 ‘여기에서 재검색’으로 조회 지역을 변경할 수 있으며, 이미 받은 지역은 메모리에 캐시합니다.
금연구역 탭에는 해당 지역 내 가까운 순으로 최대 100곳을 표시합니다. 인접 시·군·구는 포함하지 않습니다.
좌표가 없거나 유효하지 않은 항목은 지도에서 제외하며 제외 건수를 표시합니다.
금연범위, 지정근거, 위반과태료, 신고전화, 관리기관 및 데이터기준일은 상세 카드에서 확인할 수 있습니다.
API 오류는 목록 상단에 표시됩니다. 실제 금연범위는 상세 정보와 현장 안내를 확인하세요.
