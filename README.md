# 002

공공이: 지도 중심 반경 3km 안의 공공시설을 가까운 순으로 최대 100곳 표시합니다.
주소 검색 또는 ‘여기에서 재검색’으로 중심을 바꿉니다. 먼저 받은 카테고리는 다른 요청을 기다리지 않고 표시합니다.
목록과 팝업에는 데이터기준일을 표시하지 않습니다.

실행: `npm install` 후 `npm run dev`.
`.env.local`에 `VITE_KAKAO_MAP_KEY`, `VITE_DATA_GO_KR_SERVICE_KEY`를 설정합니다.

화장실, 무료와이파이, 자전거보관소는 `data` 폴더의 CSV를 원본으로 사용합니다.
Vite 시작/빌드 시 `scripts/prepare-nearby-data.mjs`가 원본을 파싱하여 좌표별 JSON 파일을 `data/nearby`에 생성합니다.
원본이 바뀌지 않았다면 다시 생성하지 않습니다. CSV를 교체한 경우 개발 서버를 재시작해주세요.
브라우저는 작은 인덱스와 반경 3km에 걸치는 지역 파일만 내려받고 재검색 시 캐시를 재사용합니다.
원본 CSV 전체를 브라우저에서 다운로드하거나 파싱하지 않습니다.
현재 와이파이/자전거 CSV는 원본 내용을 보존한 UTF-8이며, 파서는 UTF-8과 EUC-KR을 지원합니다.
좌표가 없는 항목은 제외합니다. 자전거 보관 가능 대수는 수용량이며 실시간 빈자리 수가 아닙니다.

주차장, 휴지통, 공원, 금연구역 API는 주변 지역 파일의 지자체 코드(`insttCode`)로 범위를 제한합니다.
전국 조회는 수행하지 않습니다. 경계 근처에서는 인접 지역 코드도 포함하고, 응답 좌표로 반경 3km를 다시 필터링합니다.
지역 코드 목록은 CSV 원본의 좌표/자치단체 코드에서 파생되므로 원본에 없는 제공기관은 조회 대상에서 빠질 수 있습니다.
요청은 최대 4개씩 실행하며, 각 페이지가 도착할 때 목록을 갱신합니다. 위치 변경 시 이전 요청을 취소하고 완료된 지역 응답은 재사용합니다.
오류가 난 카테고리는 안내를 표시하고, 성공한 카테고리는 계속 사용할 수 있습니다.

검증:
- `node scripts/check-file-facilities.mjs`: CSV 인코딩/필드/좌표 검사
- `node scripts/prepare-nearby-data.mjs`: 지역 파일 생성
- `node scripts/check-nearby.mjs`: 전국 원본 대비 주변 검색 결과 일치, 지역 API 필터/페이지/캐시/취소/동시 요청 검사
- `npm run lint`
- `npm run build`
